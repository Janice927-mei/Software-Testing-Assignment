# Software-Testing-Assignment

Assignment DeliverablesPart A - 
Test Plan: Create a detailed test plan outlining the scope, objectives, and test conditions using the UECS2354_TestPlan_Template.docx file.  

Part B - Test Design: Develop a Decision Table, Equivalence Partitioning (EP) table, and Boundary Value Analysis (BVA) table using the provided Excel templates. Following this, you must design corresponding test cases.  

Part C - Code Implementation: Build a Java project containing a separate directory for application code and test code. You must implement the 10 specified Java classes, though some functionalities like payment and email are only stubbed for testing.  

Final Report: Compile a report containing your assignment cover page, any assumptions made, a class diagram, and the attached code.  

Testing & Coding RequirementsFrameworks: Write your unit tests utilizing JUnit 4. 
You must also implement parameterized tests using jUnitParams.  
Test Doubles: Use Mockito to mock external dependencies, such as the printerAvailability.java and payment.java modules.  
Data Driven Testing: Configure at least some of your tests to read input values directly from a text file rather than hardcoding them.
Integration: Perform integration testing after all individual unit tests are completed.
